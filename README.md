## 7. 문서 관리 & 커밋 규칙

PRD와 테스트 보고서는 버전을 올릴 때마다 커밋으로 남겨 업데이트 과정을 추적합니다.

```
타입: 내용
```

| 타입 | 용도 | 예시 |
|---|---|---|
| `feat` | 기능 추가 | `feat: AI 요약 기능 추가` |
| `fix` | 버그 수정 | `fix: API 응답 오류 처리 수정` |
| `style` | UI/스타일 변경 | `style: 결과 카드 레이아웃 수정` |
| `docs` | 문서 작성·수정 (PRD, 테스트 보고서, 로그 포함) | `docs: PRD v1 문제 정의 작성` |
| `chore` | 설정·기타 | `chore: 배포 설정 추가` |

- 제목은 50자 이내, 한 줄, 마침표 없이 명사형으로 끝냅니다.
- 커밋 하나에 변경 하나만 담고, 필요할 때만 본문에 "왜"를 적습니다.
